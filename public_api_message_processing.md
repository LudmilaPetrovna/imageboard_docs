# Публичное API для процессинга сообщений

Сделать открытое и публичное API, чтобы можно было трансформировать текстовые посты. К примеру, пользователь оставляет пост

```
%roll
```

На выходе отображается пост с текстом

```
Вам выпало 5
```

Таким образом можно реализовать простой механизм для расширения возможностей доски. В данном случае, это простое создание механизма для подбрасывания игрального кубика.
